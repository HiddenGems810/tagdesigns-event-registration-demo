# TAGDesigns event registration demo

An original portfolio demo for a fictional event platform. It demonstrates themeable event discovery, search and filters, agenda details, and a multi-step registration interface.

## Run locally

Use Node.js 20.19 or newer and pnpm.

- Install dependencies with pnpm install.
- Start the local app with pnpm dev.
- Check types with pnpm typecheck.
- Create a production build with pnpm build.

## Demo boundaries

All event records and ticket options are fictional sample data. Registration is simulated entirely in the browser. The app has no registration API, reservation, payment, account, analytics, or persistence. The attendee fields exist only in page memory while trying the flow and are discarded when the page is reloaded or closed. Do not enter real personal information.

This demo was made by TAGDesigns as original portfolio work. It does not represent RainFocus or any other event provider, and it does not include client source code.
